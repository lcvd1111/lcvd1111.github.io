# Proposed Hierarchical Category Files

These files mirror the paths that should be added or modified in `docs/`.

Add this new file:

```text
docs/_data/category_tree.yml
```

Modify these existing files by applying the matching file from this directory:

```text
docs/_posts/2025-01-01-testpost.md
docs/_layouts/categories.html
docs/_includes/sidebar/category-list.html
```

No `docs/_config.yml` change is required for this proposal.
